- README.md

Also upload your existing logo files to the repository ROOT:
hpl.png, royal-kings.png, titans.png, chesara.png, stars.png

## Firebase
1. Create a NEW Firebase project.
2. Create Firestore Database (default database).
3. Add a Web App: HPL Season 11 Website.
4. Copy Firebase's exact config into firebase-config.js.
5. Publish firestore.rules.
6. Create collection `matches`.
7. Add match documents `match1` to `match7`.

The website has built-in Match 1–7 fallback data, so the public site does not become blank while Firebase is being configured.
